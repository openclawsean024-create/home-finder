# 找房配對助手 — PRD v3.0.2 等級規格書

> 建立日期:2026-09-19 · 對齊 SPEC v3.0 契約

## §1 產品概述

### 1.1 問題陳述
租屋族找房痛點：(1) 591 / 租屋網 / Facebook 社團分散，要切 5+ 個平台 (2) 條件搜尋不精準，常要過濾上百筆 (3) 房東聯繫後常已出租，白跑看屋。本案提供「統一搜尋 + 智能配對 + 收藏比較 + 預約看屋」。

### 1.2 目標使用者
- **Primary — 都會區上班族**：每月租 1-3 萬，6 個月租期
- **Secondary — 家庭 / 學生**：3-6 個月租期，要多條件比價

### 1.3 核心價值主張
> 一頁看完所有租屋：地圖、條件、歷史、聯絡 — 不再 5 個平台切換。

### 1.4 Non-Goals
- ❌ 真實房東資料庫（爬蟲合規問題）
- ❌ 租屋契約代書
- ❌ 房貸試算
- ❌ 國際租屋

## §3 FR

- FR-001: 多平台來源聚合（591 / 租屋網 / FB 社團 / Reddit）
- FR-002: 條件搜尋（價位 / 坪數 / 區域 / 格局 / 設施）
- FR-003: 地圖檢視（含學校 / 捷運 / 商圈 overlay）
- FR-004: 收藏 + 比較（最多 5 筆並排）
- FR-005: 房東聯繫記錄 + 跟進提醒
- FR-006: 看屋預約（行事曆）

## §4 NFR

- 搜尋結果 < 2 秒
- 支援 Web + Mobile responsive
- localStorage 收藏同步

## §5 技術棧
